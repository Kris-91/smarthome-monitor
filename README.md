# 🏠 SmartHome IoT — 智能家居物联网监控平台

面向物联网专业课程作业的智能家居模拟监控网页应用。纯前端实现，模拟传感器数据驱动。

## ✨ 功能

- 🏠 **仪表盘** — 全屋概览（平均温度/最高温度/设备在线数/活跃告警），4个房间传感器实时卡片
- 📊 **数据监控** — Chart.js 实时曲线图，支持单房间 + 全屋对比，阈值参考线
- 🎛️ **设备控制** — 灯光/空调/窗帘/排气扇开关，全屋总控 + 居家/离家/睡眠场景模式
- ⚙️ **告警管理** — 温度/湿度/烟雾阈值配置，告警历史（含筛选）+ 声音提示
- 🌙 **深色科技风** UI — 物联网监控中心风格，桌面+平板适配

## 🛠 技术栈

- HTML/CSS/JavaScript（纯前端，无框架）
- Chart.js v4 CDN — 实时传感器曲线
- localStorage — 设备状态 + 告警历史持久化

## 📁 模拟范围

| 房间 | 传感器 | 可控设备 |
|------|--------|----------|
| 🛋️ 客厅 | 温度、湿度、光照 | 主灯、空调、窗帘 |
| 🛏️ 卧室 | 温度、湿度、光照 | 主灯、空调、窗帘 |
| 🍳 厨房 | 温度、湿度、烟雾 | 灯、排气扇 |
| 🚿 卫生间 | 温度、湿度 | 灯、排风扇 |

- 数据每 **2秒** 自动刷新，含自然波动
- 光照模拟日间/夜间变化，厨房烟雾偶发尖峰
- 告警冷却 10秒（同一房间+类型不重复告警）
