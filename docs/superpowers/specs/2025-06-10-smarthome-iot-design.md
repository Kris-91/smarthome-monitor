# SmartHome IoT — 智能家居物联网监控平台 设计文档

> 日期: 2025-06-10 | 状态: 已确认 | 部署: GitHub Pages

## 1. 概述

面向物联网专业课程作业的智能家居模拟监控网页应用。纯前端实现，模拟传感器数据驱动，提供实时监控、设备控制、告警管理三大核心功能。覆盖客厅/卧室/厨房/卫生间4个房间，每个房间含温度/湿度/光照/烟雾传感器和可控设备。

## 2. 技术选型

| 层 | 选择 | 说明 |
|----|------|------|
| 结构 | HTML5 | 单页应用，4标签页 |
| 样式 | CSS3 自定义属性 | 深色科技风主题 |
| 逻辑 | Vanilla JS (ES6+) | 无框架，类模块化 |
| 图表 | Chart.js v4 CDN | 实时传感器曲线 |
| 图标 | Unicode/emoji | 无外部图标库依赖 |
| 存储 | localStorage | 告警历史持久化 |
| 部署 | GitHub Pages | 公开URL，零配置 |

### 3.1 首页仪表盘 (Dashboard)
- 4张房间卡片，每张显示：房间名、当前温度/湿度/光照数值、设备在线数
- 顶部全屋概览：平均温度、最高温度、活跃告警数
- 最新3条告警滚动条
- 传感器数据每2秒刷新

### 3.2 数据监控 (Data Monitor)
- 房间选择器 + 指标选择器（温度/湿度/光照/烟雾）
- Chart.js 实时折线图，保留最近200个数据点
- X轴时间戳，Y轴自适应
- 支持切换房间实时对比

### 3.3 设备控制 (Device Control)
- 按4个房间分组，每组展开式卡片
- 每个设备：大圆形开关按钮 + 状态指示灯（绿=开/灰=关）
- 点击即时切换状态，带过渡动画
- 设备列表：主灯、空调、窗帘、排气扇等

### 3.4 告警设置 (Alert Settings)
- 阈值配置面板：高温线、低温线、高湿线、烟雾浓度线
- 告警规则引擎实时检测
- 告警历史列表（时间/房间/类型/数值），支持清除
- 新告警时标题栏铃铛图标脉冲动画

## 4. 房间与设备模型

### 4.1 房间定义

```javascript
rooms = [
  { id: 'living',  name: '客厅', icon: '🛋️', sensors: ['temp','humidity','light'],          devices: ['主灯','空调','窗帘'] },
  { id: 'bedroom', name: '卧室', icon: '🛏️', sensors: ['temp','humidity','light'],          devices: ['主灯','空调','窗帘'] },
  { id: 'kitchen', name: '厨房', icon: '🍳', sensors: ['temp','humidity','smoke'],          devices: ['灯','排气扇'] },
  { id: 'bathroom',name: '卫生间',icon: '🚿',sensors: ['temp','humidity'],                  devices: ['灯','排风扇'] },
]
```

### 4.2 传感器数据范围

| 传感器 | 范围 | 波动策略 | 房间差异 |
|--------|------|----------|----------|
| 温度 | 18-35°C | ±0.3°C/次 | 厨房+1.5°C, 卧室-0.5°C |
| 湿度 | 30-90% | ±1%/次 | 卫生间+8%, 客厅-3% |
| 光照 | 0-1000 lux | ±30/次 | 日间模拟(6-18点偏高) |
| 烟雾 | 0-800 ppm | ±5/次 | 厨房基线200, 偶发500+ |

### 4.3 告警阈值（可配置）

| 规则 | 默认值 | 触发条件 |
|------|--------|----------|
| 高温告警 | 32°C | 任意房间温度 > 32 |
| 烟雾告警 | 500 ppm | 烟雾 > 500 |
| 高湿告警 | 85% | 湿度 > 85% |

## 7. 异常与边界处理

- Chart.js CDN 失败 → 图表区显示"图表加载失败"文字提示
- localStorage 不可用 → 仅内存运行，告警不持久化
- 传感器值异常（NaN/Infinity）→ 显示"--"并跳过告警检测
- 所有定时器在页面隐藏时暂停（Page Visibility API）
